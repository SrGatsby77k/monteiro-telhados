BACKEND
  • 01
    Usuário e senha
    O servidor valida as contas; as senhas são armazenadas como hashes scrypt e nunca no HTML.
  • 02
    Contas individuais
    Cadastro público desativado. O administrador cria usuários pelo terminal do servidor.
  • 03
    Sites confiáveis
    Os atalhos ficam no armazenamento local deste navegador, separados por usuário; ainda não sincronizam com a nuvem.
  • 04
    Busca de telefones
    Conecte somente um provedor legítimo, com base legal, consentimento e limites de uso adequados.
  • 05
    Assistente OpenAI
    O servidor local encaminha as perguntas à API sem expor a chave no navegador. Configure a chave como variável de ambiente.
